# boardswitcher

Небольшая программа для Linux (X11, KDE Plasma 5): по нажатию **Caps Lock** меняет
раскладку последнего набранного слова или выделенного текста («ghbdtn» ↔ «привет»)
и сразу переключает раскладку системы. Минимальный аналог Punto Switcher.

> **Статус: личный инструмент, публикуется «как есть».** Написана для одного
> конкретного окружения (RedOS 8, KDE Plasma 5, X11, две раскладки us/ru) и
> проверена в основном там. Автоматических тестов нет. Подробности и ограничения
> ниже, в разделах «Ограничения» и «Происхождение кода».

## Что делает

Одна клавиша, Caps Lock, работает так:

| Ситуация | Что происходит |
|---|---|
| Вы только что набрали слово (после него не было клика мышью, Enter, стрелок и т. п.) | Слово стирается и набирается заново в другой раскладке. Пробелы, набранные после слова, сохраняются. |
| Слова нет, но есть выделенный текст | Выделенный текст заменяется его вариантом в другой раскладке. |
| Нет ни слова, ни выделения (или выделены одни пробелы и переводы строки) | Ничего не вставляется, раскладка системы просто переключается. |

Во всех случаях раскладка системы после нажатия ставится в ту, в которой теперь находится текст.
Повторное нажатие возвращает слово обратно. Режим «заглавные буквы» Caps Lock при этом
**не используется**: заглавные набираются через Shift.

Если в выделенном тексте смешаны две раскладки, меняется та, которой в тексте больше
(по буквам, у которых есть соответствие в другой раскладке). Буквы другой раскладки остаются как есть.

## Требования

- Linux с графической сессией **X11** (в Wayland не работает, см. «Ограничения»).
- KDE Plasma 5 (автозапуск описан для KDE; саму программу можно запускать и в другой X11-среде).
- Ровно две раскладки в системе (например, `us,ru`).
- Python 3, `python3-xlib`, `xclip`, `libX11`.
- Необязательно: `python3-qt5` для значка в трее (в готовом пакете значок отключён).

Проверялось на RedOS 8 (KDE Plasma 5), раскладки `us,ru` (у автора вторая раскладка с вариантом `chm`).

## Установка

### Из готового rpm (RedOS, Fedora-подобные системы)

```bash
sudo dnf install -y ./boardswitcher-1.0-5.noarch.rpm
```

Пакет сам подтянет зависимости (`python3-xlib`, `xclip`, `libX11`), положит программу в
`/usr/bin/boardswitcher`, добавит автозапуск для пользователя при входе в KDE
(`/etc/xdg/autostart/boardswitcher.desktop`) и пункт «boardswitcher» в раздел «Офис» меню программ.
Системные настройки клавиатуры пакет **не меняет** (см. следующий раздел).

### Из исходников

```bash
sudo dnf install -y python3-xlib xclip
sudo install -Dm0755 boardswitcher /usr/local/bin/boardswitcher
boardswitcher --no-tray
```

Автозапуск при необходимости настройте сами (скопируйте `boardswitcher.desktop`
в `~/.config/autostart/` и поправьте строку `Exec=`).

## Обязательная настройка системы

Программа сама ловит Caps Lock и сама переключает раскладку, поэтому у клавиши в системе
должно быть **отключено штатное поведение**:

1. Из настроек клавиатуры нужно убрать переключение раскладки на Caps Lock
   (опция XKB `grp:caps_toggle`), иначе раскладку будут переключать и система, и программа.
2. Нужно отключить режим заглавных букв у Caps Lock: опция XKB `caps:none`.
   Иначе при каждом нажатии будет включаться режим заглавных.

Проверить текущие опции:

```bash
setxkbmap -query | grep options
```

Должны присутствовать `caps:none`, а `grp:caps_toggle` быть нет.

**Временно** (до выхода из сессии, настройки KDE не трогает; остальные опции перечислите свои):

```bash
setxkbmap -option "" -option grp:alt_shift_toggle,lv3:ralt_switch,kpdl:dot,caps:none
```

**Постоянно в KDE Plasma 5**: «Параметры системы → Устройства ввода → Клавиатура → Дополнительно»
(пункты называются примерно «Переключение на другую раскладку» и «Поведение клавиши Caps Lock»;
точные названия зависят от версии). Либо правкой файла настроек: в `~/.config/kxkbrc` в секции
`[Layout]` в строку `Options=` через запятую добавляется `caps:none`. Например:

```bash
kwriteconfig5 --file kxkbrc --group Layout --key Options "grp:alt_shift_toggle,kpdl:dot,lv3:ralt_switch,caps:none"
```

Подставьте свои текущие опции (посмотреть: `grep -A8 '^\[Layout\]' ~/.config/kxkbrc`) и добавьте
`caps:none`. Как правило, изменение подхватывается при следующем входе в систему; если этого не
произошло, задайте настройку через графический интерфейс. Все остальные клавиши
переключения раскладки (например, Alt+Shift) можно оставить: они работают независимо от программы.

## Использование

1. Набрали слово не в той раскладке: нажмите **Caps Lock**. Слово исправится, раскладка переключится.
2. Нажали **Caps Lock** ещё раз сразу после этого: слово вернётся к исходному виду.
3. Нужно исправить уже написанный текст: выделите его и нажмите **Caps Lock**.
4. Нужно просто переключить раскладку, не трогая текст: нажмите **Caps Lock** без набранного слова и без выделения.

Что «забывает» слово (после этого Caps Lock будет работать как «выделенный текст / переключение»):
Enter, любая клавиша без символа (стрелки, Tab, Esc, F1–F12 и т. п.), сочетания с Ctrl, Alt или Super,
клик левой, средней или правой кнопкой мыши, слово длиннее 200 символов.
Backspace убирает последнюю букву слова, пробелы после слова запоминаются и возвращаются на место.

## Запуск, остановка, отладка

- **Автозапуск:** при входе в KDE, от имени вошедшего пользователя.
- **Вручную:** `boardswitcher --no-tray` (запустится в фоне, терминал можно оставить открытым).
  Пункт «boardswitcher» в разделе «Офис» делает то же самое. Если программа уже работает,
  повторный запуск ничего не делает и пишет «boardswitcher уже запущен».
- **Остановка:** `pkill -f '[b]oardswitcher'` либо завершить процесс в «Системном мониторе».
- **Ключи:** `--no-tray` (без значка в трее), `--debug` (подробный вывод в терминал).
- **Значок в трее** включается запуском без `--no-tray` (нужен `python3-qt5`; меню: «Включено» и «Выход»).
  Эта часть **не проверялась** на реальной системе, в пакете по умолчанию отключена.

Внимание: при `--debug` в терминал выводится **набранное слово и выделенный текст**.
Не запускайте отладку при работе с паролями и закрытыми данными и не пересылайте такой вывод другим.

## Как это работает

- **Слежение за клавишами.** Через расширение X11 RECORD программа получает события нажатия клавиш
  и кликов мыши во всех окнах. Для текущего слова хранится список кодов клавиш с уровнем (с Shift или без)
  и группой (раскладкой). Сами буквы строятся из таблицы клавиатуры X-сервера, поэтому
  таблицы соответствий «us ↔ ru» не зашиты в код и учитывают вариант раскладки.
- **Замена слова.** Программа отправляет столько Backspace, сколько в слове букв и пробелов после него,
  затем вставляет результат через буфер обмена и сочетание Shift+Insert. Это сочетание не зависит
  от раскладки, в отличие от Ctrl+V.
- **Замена выделения.** Через Ctrl+Insert выделенный текст копируется в буфер, преобразуется и
  вставляется обратно через Shift+Insert. Состояние буфера до операции запоминается и восстанавливается.
- **Раскладка системы.** Переключается вызовом `XkbLockGroup` из libX11 на группу, в которой теперь текст.
- **Нажатия, отправленные самой программой,** игнорируются (около 0,3 секунды после действия).

## Приватность и безопасность

Программа читает **все нажатия клавиш во всех окнах**. Технически это то же, что делает кейлоггер,
поэтому ниже написано в точности, что она делает и чего не делает (описано по исходному коду, он короткий,
рекомендуется прочитать его целиком перед установкой).

**Что делает**
- Держит в оперативной памяти коды клавиш текущего слова (не больше 200). Слово забывается по правилам выше.
- Для работы временно подменяет содержимое буфера обмена (CLIPBOARD) и перезаписывает выделение PRIMARY
  результатом конвертации. Прежний **текст** в CLIPBOARD восстанавливается примерно через полсекунды.
- Запускает внешние программы `xclip` и `setxkbmap`.
- Создаёт файл блокировки `boardswitcher.lock` в `$XDG_RUNTIME_DIR` (или в `/tmp`), чтобы не запускаться дважды.

**Чего не делает**
- Не пишет набранный текст ни в файлы, ни в журналы (кроме режима `--debug`, который печатает в терминал).
- Не обращается к сети, не отправляет данные.
- Не требует прав root при работе и не меняет системные настройки.

**Что стоит знать**
- В полях ввода паролей программа тоже видит нажатия. Если нажать Caps Lock сразу после ввода пароля,
  набранное слово будет перенабрано в другой раскладке (и попадёт в поле). Не нажимайте её в таких полях.
- Если у вас менеджер буфера обмена с историей (например, Klipper), в историю попадут служебные значения
  и результаты конвертации.
- Если в буфере обмена до операции было не текстовое содержимое (например, картинка), оно будет потеряно.
- Лучше не использовать на общих или недоверенных машинах.

## Ограничения

- **Только X11.** В Wayland не работает (программа предупреждает при старте).
- **Две раскладки.** Берутся первые две группы клавиатуры X-сервера. Третья и последующие не поддерживаются;
  при выборе такой раскладки слово «забывается».
- **Клавиша жёстко задана:** физическая клавиша с кодом 66 (Caps Lock на стандартной клавиатуре Linux/evdev).
  Настраиваемых клавиш нет.
- **Символы третьего уровня** (набираемые с правым Alt, `lv3:ralt_switch`) не конвертируются, а набор слова
  с ними может исказить результат.
- Таблицы раскладок строятся один раз при запуске. Если вы изменили раскладки, перезапустите программу.
- Приложения с автозаменой или автодополнением могут разойтись с тем, что запомнила программа:
  стёртое число букв не совпадёт с набранным.
- Приложения, где Ctrl+Insert не копирует, а Shift+Insert не вставляет, не поддерживаются.
- Некоторые программы при Ctrl+Insert без выделения копируют строку целиком (например, Kate). Тогда
  команда по строке без выделения может заменить текущую строку её конвертированной копией.
  Если вам это мешает, не нажимайте Caps Lock в таких случаях без слова и без выделения.
- Не поддерживаются Wine-программы, удалённые сеансы (RDP, VNC) и виртуальные машины
  (синтетические нажатия и буфер обмена там часто не доходят). Не проверялись.
- Программа не определяет автоматически, что слово набрано не в той раскладке: действует только по клавише.
- Перед действием программа программно «отпускает» зажатые Shift, Ctrl, Alt и Super.
  При очень быстром наборе возможны единичные потери символов.
- Автотестов нет. Проверена вручную в одном окружении.

## Если что-то не работает

| Симптом | Вероятная причина и что делать |
|---|---|
| Ничего не происходит | Программа не запущена. Запустите `boardswitcher --no-tray --debug` в терминале: должна появиться строка «boardswitcher запущен». Проверьте, что сессия X11: `echo $XDG_SESSION_TYPE` должно дать `x11`. |
| Caps Lock включает заглавные буквы | В системе не отключён `caps:none`. См. «Обязательная настройка системы». |
| Раскладка переключается дважды (меняется и сразу возвращается) | В системе остался `grp:caps_toggle`. Уберите его. |
| После нажатия слово остаётся прежним, а раскладка меняется | В слове были клавиши, которые программа «забывает» (Ctrl, стрелки и т. п.), либо перед словом был клик мышью. Нажмите Caps Lock ещё раз, либо выделите слово. |
| Вставляется старый текст из буфера | Приложение вставляет с задержкой. Сообщите, в каком приложении: время ожидания можно увеличить в коде. |
| Не работает в одном приложении | Проверьте вручную: работают ли в нём Ctrl+Insert (копировать) и Shift+Insert (вставить). |
| Две копии программы | Не должно быть: второй экземпляр завершается сразу. Проверьте `pgrep -fa '[b]oardswitcher'`. |

## Сборка пакета

Нужны `make` и `rpm-build`:

```bash
make dist    # архив исходников dist/boardswitcher-1.0.tar.gz
make rpm     # rpm и src.rpm в dist/rpmbuild/RPMS и dist/rpmbuild/SRPMS
```

Сборка не требует компиляции (пакет `noarch`).

## Удаление

```bash
pkill -f '[b]oardswitcher'
sudo dnf remove -y boardswitcher
```

Если вы добавляли `caps:none` в настройки клавиатуры, верните настройки по своему усмотрению.

## English summary

**boardswitcher** is a tiny X11 tool (tested on RedOS 8 / KDE Plasma 5) that converts the last typed
word, or the selected text, to the other keyboard layout (e.g. `ghbdtn` ↔ `привет`) when you press
**Caps Lock**, and switches the system layout to match. Pressing it again undoes the conversion;
with no word and no selection it simply toggles the layout.

- **Requirements:** X11 session (no Wayland), exactly two layouts, Python 3, `python3-xlib`, `xclip`, `libX11`.
- **Required system setup:** Caps Lock must not toggle layouts or caps: remove `grp:caps_toggle` and add
  `caps:none` to your XKB options (see *Обязательная настройка системы* above).
- **Install:** `sudo dnf install ./boardswitcher-1.0-5.noarch.rpm` (adds KDE autostart and an application-menu entry).
- **Privacy:** it reads all key presses via the X11 RECORD extension, keeps only the current word's key codes
  in memory, temporarily replaces the clipboard text and restores it, does not use the network and writes
  nothing to disk (except a lock file); `--debug` prints typed/selected text to the terminal.
- **Limitations:** two layouts only, hard-coded key (keycode 66), no level-3 symbols, no Wine/RDP/VM support,
  no automated tests, tested manually in one environment.
- **Provenance:** written with the help of an AI assistant (Claude, by Anthropic) to the author's requirements;
  please read the single-file source before relying on it.
- **License:** MIT. Not affiliated with Punto Switcher or its owner.
