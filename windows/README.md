# boardswitcher для Windows

Версия [boardswitcher](../README.md) для Windows 10/11: по нажатию **Caps Lock** меняет раскладку
последнего набранного слова или выделенного текста («ghbdtn» ↔ «привет») и сразу переключает
раскладку. Поведение то же, что в версии для Linux.

## Что делает

| Ситуация | Что происходит |
|---|---|
| Вы только что набрали слово (после него не было клика мышью, Enter, стрелок и т. п.) | Слово стирается и набирается заново в другой раскладке. Пробелы, набранные после слова, сохраняются. |
| Слова нет, но есть выделенный текст | Выделенный текст заменяется его вариантом в другой раскладке. |
| Нет ни слова, ни выделения (или выделены одни пробелы и переводы строки) | Ничего не вставляется, раскладка просто переключается. |

Повторное нажатие возвращает слово обратно. Режим заглавных букв Caps Lock не включается:
программа перехватывает клавишу целиком, заглавные набираются через Shift. Если программу выключить,
Caps Lock снова работает как обычно.

Слово «забывается» после Enter, клавиш без символа (стрелки, Tab, Esc, F1–F12 и т. п.), сочетаний
с Ctrl, Alt или Win, клика мышью и если в нём больше 200 символов. Backspace убирает последнюю букву.

## Установка

Запустите `boardswitcher-setup-1.2.0.exe`. Установщик:

- ставит программу в `C:\Program Files\boardswitcher` (нужно разрешение администратора);
- если нет .NET 10 Desktop Runtime, сам скачивает его с сайта Microsoft и устанавливает;
- добавляет ярлык в меню «Пуск» и, по желанию, на рабочий стол;
- по желанию включает автозапуск и запуск с правами администратора (эти же галочки есть в настройках).

Удаление: «Параметры → Приложения → boardswitcher → Удалить». Удаляются программа, ярлыки,
задача автозапуска, настройки и журнал.

Нужны две раскладки клавиатуры (например, английская и русская). Используются первые две из списка.

## Настройки

Значок «Ая» в трее (синий — включено, серый — выключено). Двойной щелчок или «Настройки…» в меню
открывает окно настроек. Повторный запуск программы из «Пуска» тоже открывает настройки.

| Настройка | Что делает |
|---|---|
| Включено | Caps Lock меняет раскладку. Быстро переключается и в меню трея. |
| Запускать при входе в Windows | Автозапуск через задачу Планировщика заданий (`boardswitcher-<пользователь>`). |
| Запускать с правами администратора | Программа работает и в окнах, открытых от имени администратора. |
| Вести журнал (отладка) | Журнал в `C:\Users\<пользователь>\boardswitcher.log`. |

**Права администратора.** Windows не даёт программе с обычными правами видеть нажатия и вводить текст
в окнах, запущенных от имени администратора. При включении настройки Windows один раз спрашивает
разрешение (UAC), создаётся задача Планировщика с наивысшими правами, программа перезапускается.
Дальше она стартует с правами администратора без вопросов: и при входе в Windows, и из ярлыка
в «Пуске». Если разрешение не дано, программа работает с обычными правами и предупреждает об этом.

**Журнал.** Записывает запуск, раскладки, каждое нажатие Caps Lock (слово или выделение до и после,
переключение раскладки) и ошибки. В журнал попадают набранные слова и выделенный текст, поэтому
по умолчанию он выключен. Не включайте его при работе с паролями. На один запуск журнал можно
включить ключом `--debug`.

Настройки хранятся в `HKCU\Software\boardswitcher`.

## Сборка

Нужны .NET SDK 10 и, для установщика, Inno Setup 6 (`winget install JRSoftware.InnoSetup`).
Проект открывается в Visual Studio (`boardswitcher.csproj`). Из командной строки:

```
.\build.ps1               # exe (publish\boardswitcher.exe) и установщик (installer\Output\)
.\build.ps1 -NoInstaller  # только exe
```

## Как это работает

- **Слежение за клавишами:** низкоуровневый перехват клавиатуры и мыши (`WH_KEYBOARD_LL`, `WH_MOUSE_LL`).
  Для текущего слова хранятся коды клавиш, уровень (с Shift или без) и раскладка.
- **Таблицы символов** строятся из раскладок Windows (`ToUnicodeEx`), а не зашиты в код.
- **Замена слова:** Backspace по числу букв и пробелов, затем набор результата символами Unicode
  (`SendInput`). Буфер обмена при этом не используется.
- **Замена выделения:** Ctrl+Insert (копировать), преобразование, Shift+Insert (вставить). Прежний текст
  буфера обмена восстанавливается. Служебные значения помечаются, чтобы журнал буфера обмена (Win+V) их не сохранял.
- **Раскладка** переключается сообщением `WM_INPUTLANGCHANGEREQUEST` активному окну.
- Нажатия, отправленные самой программой (и другими программами), не учитываются.

## Приватность

Программа видит все нажатия клавиш во всех окнах. Она держит в памяти только коды клавиш текущего
слова (не больше 200), не пишет набранный текст на диск (кроме включённого журнала) и не обращается
к сети. Если до операции с выделением в буфере обмена было не текстовое содержимое (например, картинка),
оно теряется. В полях паролей нажатия тоже видны: не нажимайте Caps Lock сразу после ввода пароля.
С включённой настройкой «права администратора» программа работает с этими правами.

## Безопасность режима администратора

Программа с правами администратора, которая следит за клавиатурой, — лакомая цель: любая программа
с правами пользователя могла бы попытаться через неё получить права администратора без вопроса UAC.
Поэтому:

- Режим доступен только для программы, установленной в `C:\Program Files`, куда без прав администратора
  писать нельзя. Из другой папки галочка неактивна, а задача с наивысшими правами не создаётся.
- Задача Планировщика регистрируется через COM-интерфейс Планировщика, без временных файлов и без запуска
  `schtasks.exe`. Системные программы (Проводник) запускаются по полному пути.
- Журнал пишется только в обычный файл: если на его месте оказалась символьная или жёсткая ссылка,
  запись не выполняется. Из копии с правами администратора журнал открывается с правами пользователя.
- Загрузка кода через переменную `DOTNET_STARTUP_HOOKS` отключена.
- Установщик проверяет цифровую подпись Microsoft у скачанного .NET перед установкой.

**Остаточный риск.** Среда .NET при запуске читает переменные окружения пользователя (`DOTNET_ROOT`,
`CORECLR_PROFILER…`) раньше, чем начинает работать сама программа. Программа с правами пользователя может их
задать и запустить задачу boardswitcher, получив свой код в процессе с правами администратора. Это общее
свойство .NET-программ, которые запускаются с повышенными правами без UAC, закрыть его изнутри программы нельзя.
Microsoft не считает UAC границей безопасности для учётных записей администраторов. Если такой риск
неприемлем, не включайте режим администратора.

## Ограничения

- Только две первые раскладки из списка. При третьей раскладке слово «забывается».
- Без настройки «права администратора» не работает в окнах администратора.
- Приложения, где Ctrl+Insert не копирует, а Shift+Insert не вставляет, не поддерживаются для выделения.
- Приложения с автозаменой или автодополнением могут разойтись с тем, что запомнила программа.
- В смешанном тексте вместе с буквами меняется и пунктуация преобладающей раскладки (как в версии для Linux).
- Автотестов нет.
